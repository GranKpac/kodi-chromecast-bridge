Kodi Chromecast Bridge

Repositorio experimental de complementos Kodi del proyecto Kodi Chromecast Bridge.

Para instalarlo, descarga repository.kodichromecastbridge-0.1.0.zip y en Kodi selecciona Add-ons → Instalar desde un archivo ZIP.

Después, abre Instalar desde repositorio → Kodi Chromecast Bridge Repository → Add-ons de programas e instala Kodi Cast Diagnostic.

El complemento de diagnóstico consulta la fuente de reproducción actual. No muestra la URL completa, los parámetros de consulta ni los valores de las cabeceras.
